## Register
Brand — 设计即产品。H5 移动端趣味测评，情绪体验和社交传播优先。

## Users & Purpose
- **用户**：小红书 18-35 岁女性，自我认知/人设标签需求
- **场景**：碎片时间，手机竖屏，从社媒帖子引流
- **任务**：快速完成测评 → 获得人设标签 → 截图分享 → 裂变

## Brand Personality
自信 / 多元 / 有趣
像一个懂你的朋友在帮你发现自己——不评判、不贴标签、鼓励每一种风格。

## Tone by Grade
| 等级 | 语气 |
|------|------|
| S 级 👑 | 你就是标杆，自信放光芒 |
| A 级 💎 | 已经很棒了，还有小空间 |
| B 级 🌟 | 潜力在线，继续发光 |
| C 级 📝 | 温柔提醒，别太放飞 |
| D 级 ⚠️ | 直白但不过分，值得反思 |

## Anti-References
- 不要像心理学报告
- 不要像问卷星/小程序模板
- 不做露骨色情内容
- 不称"算命""占卜"

## Visual Identity
- **主色调**：薰衣草紫（#A78BFA ~ #C4B5FD）
- **辅助色**：玫瑰金（#E8A87C）、暖金（#FCD34D）
- **形状语言**：大圆角（16-24px）
- **动效**：弹跳、弹簧物理
- **字体**：系统中文字体优先

## Design Principles
1. 结果要好看 → 社交货币
2. 巴纳姆效应 → 每种人设都有共鸣
3. 尊重多元 → 不搞"好女友"规训
4. 页面标注"由 AI 生成，仅供娱乐参考"
