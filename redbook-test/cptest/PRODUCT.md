## Register
Brand — 设计即产品。H5 移动端趣味测评，情绪体验和社交传播优先于功能效率。

## Users & Purpose
- **用户**：小红书 18-35 岁女性，关注情感/星座/性格测试，愿为情绪价值小额付费
- **场景**：碎片时间，手机竖屏，从社媒帖子引流进入
- **任务**：快速完成测评 → 获得有共鸣的结果 → 截图分享到社媒 → 产生裂变

## Brand Personality
可爱 / 搞怪 / 闺蜜

像一个最懂她的损友在说话——敢吐槽、会夸人、偶尔毒舌但永远站她这边。

## Tone by Grade
| 等级 | 语气 |
|------|------|
| S 级 | 羡慕+祝福，夸爆 |
| A 级 | 肯定+鼓励，小建议 |
| B 级 | 调侃+警示，有希望 |
| C 级 | 担忧+提醒，严肃 |
| D 级 | 心疼+力挺，劝分 |

## Anti-References
- 不要像心理学报告（冰冷、学术、数据图表堆砌）
- 不要像问卷星/小程序模板（千篇一律、灰底蓝按钮、无个性）
- 不要像 AI 默认风格（Inter 字体、紫色渐变、三列等大卡片）
- 不做露骨色情内容
- 不称"算命""占卜"，定位为"娱乐测试""心理分析"

## Visual Identity
- **主色调**：粉色系（#FF6B9D ~ #FFA0C4），暖而不腻
- **辅助色**：珊瑚橙（#FF8C69）、暖黄（#FFD93D）
- **形状语言**：大圆角（16-24px），糖果感，杜绝直角
- **动效**：弹跳、弹簧物理、轻微摇摆，有生命力但不晕
- **字体**：系统中文字体优先（苹方/微软雅黑），不用 Google Fonts

## Design Principles
1. 结果要好看 → 社交货币，截图分享即传播
2. 巴纳姆效应 → 用模糊但感觉精准的描述
3. 低门槛 + 阶梯定价 → 免费引流转付费
4. 页面标注"由 AI 生成，仅供娱乐参考"
